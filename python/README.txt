Lien bundles the official CPython 3.10.11 Windows embeddable package (x86-64).

It is an isolated runtime used only by "Launch Lien.bat". Nothing is
installed, no system PATH is changed, and no third-party Python packages are
included or required.

Python's license is included in LICENSE.txt. The runtime can be replaced with
another compatible x64 embeddable CPython distribution by replacing this
directory and updating the corresponding python3xx._pth filename/content.
